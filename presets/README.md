# GUI parameter presets

Use **GUI parameters → Save current to file / Load from file** to save and load
the original spektrafilm GUI-state JSON files.

In spektrafilm-Table this folder is the initial suggested location. After a
successful save or load, both dialogs start in the last directory you used.
You can choose any directory; using this folder is optional. Installed copies
without a writable source checkout use the local app-data `spektrafilm-Table/presets`
directory instead.

Personal preset files are ignored by Git. This folder does not contain bundled
film looks and is separate from the application's startup-default settings.
